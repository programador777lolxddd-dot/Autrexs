# Seguridad

No incluyas contraseñas, claves API, tokens ni información privada en issues o commits.

Para reportar una vulnerabilidad, contacta de forma privada con la persona mantenedora mediante las opciones de contacto de GitHub. Incluye pasos para reproducirla, el impacto y una posible mitigación. Evita publicar detalles explotables antes de que exista una solución.

Autrexs es un proyecto en desarrollo; no debe considerarse un sistema de cronometraje certificado ni usarse como única fuente para tareas críticas.
