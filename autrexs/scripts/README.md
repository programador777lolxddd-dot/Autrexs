# Módulos

- `app.js`: conecta los controles de la página.
- `clock.js` y `format.js`: presentación de fecha y hora.
- `stopwatch.js`: medición monotónica del cronómetro.
- `timer.js`, `alarms.js` y `world-clock.js`: helpers experimentales aún no integrados.
- `storage.js` y `preferences.js`: preferencias locales opcionales.
