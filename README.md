# Autrexs

**Un reloj moderno, preciso y extensible.**

Autrexs es un proyecto experimental de reloj avanzado, creado para explorar una experiencia de tiempo clara, rápida y personalizable.

> Estado: desarrollo inicial. Algunas funciones descritas en la documentación son planes de desarrollo y no deben considerarse implementadas hasta que exista código y pruebas que lo confirmen.

## Objetivos

- Mostrar hora y fecha de forma legible.
- Separar la lógica de tiempo de la interfaz.
- Mantener el proyecto ligero y fácil de ejecutar.
- Añadir temporizador, cronómetro, alarmas y zonas horarias por etapas.
- Probar las funciones automáticamente.

## Estructura

La carpeta `autrexs/` contiene una base de aplicación web estática y modular. `docs/` explica el diseño y las decisiones; `tests/` contiene pruebas; `.github/workflows/` automatiza validaciones básicas.

## Ejecutar

Abre `autrexs/index.html` en un navegador moderno. No necesita instalación ni claves API.
