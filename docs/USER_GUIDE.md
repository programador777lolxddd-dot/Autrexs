# Guía rápida

1. Abre Autrexs en un navegador moderno.
2. Consulta la hora y fecha locales.
3. Pulsa **Iniciar** para comenzar el cronómetro.
4. Pulsa **Vuelta** mientras corre para guardar una marca.
5. Pulsa **Pausar** y después **Continuar** para retomar.
6. Pulsa **Reiniciar** para volver a cero y borrar las vueltas.
