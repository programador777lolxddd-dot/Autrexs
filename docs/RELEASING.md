# Publicar una versión

1. Ejecuta las pruebas y revisa la app en navegadores objetivo.
2. Actualiza `CHANGELOG.md` y la versión.
3. Comprueba enlaces, accesibilidad y funcionamiento.
4. Crea una etiqueta solo cuando el autor confirme que está lista.
5. Incluye limitaciones conocidas en las notas de publicación.
