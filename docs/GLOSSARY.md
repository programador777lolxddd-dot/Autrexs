# Glosario

- **Hora civil:** hora del sistema, sujeta a ajustes y zona horaria.
- **Tiempo monotónico:** contador adecuado para medir intervalos.
- **Zona horaria:** reglas regionales que determinan la hora local.
- **Módulo ES:** archivo JavaScript que exporta e importa funciones.
- **Accesibilidad:** diseño usable con distintas capacidades y dispositivos.
