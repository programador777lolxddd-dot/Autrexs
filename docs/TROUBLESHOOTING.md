# Solución de problemas

- **Hora incorrecta:** revisa la hora y zona horaria del sistema.
- **Los módulos no cargan al abrir el archivo directamente:** sirve el proyecto con un servidor estático local.
- **Actualización lenta en segundo plano:** los navegadores pueden suspender pestañas.
- **Diseño estrecho:** prueba el zoom predeterminado y una ventana más ancha.
