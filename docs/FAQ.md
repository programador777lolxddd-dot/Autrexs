# Preguntas frecuentes

### ¿Necesita instalación?
La interfaz se sirve como sitio estático; para pruebas se necesita Node.js.

### ¿La hora viene de un servidor?
No. Se utiliza el reloj del dispositivo.

### ¿Es un reloj certificado?
No, es un proyecto experimental.

### ¿Ya tiene alarmas y temporizador?
Hay módulos de base, pero todavía no están integrados como funciones completas en la interfaz.
