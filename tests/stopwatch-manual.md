# Prueba manual del cronómetro

- [ ] Iniciar hace avanzar el contador.
- [ ] Pausar congela el valor visible.
- [ ] Continuar retoma sin reiniciar.
- [ ] Vuelta añade una marca legible.
- [ ] Reiniciar vuelve a cero y borra las vueltas.
- [ ] Vuelta está desactivada mientras el cronómetro está parado.
- [ ] Todos los controles se pueden usar con teclado.
