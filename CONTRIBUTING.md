# Contribuir a Autrexs

¡Gracias por ayudar! Mantén los cambios pequeños, explica el motivo y evita afirmar que una función está terminada si no tiene pruebas.

## Flujo recomendado
1. Crea una rama para tu cambio.
2. Describe el problema y la solución.
3. Prueba la aplicación en un navegador moderno.
4. Añade o actualiza pruebas cuando cambie la lógica.
5. Documenta las limitaciones conocidas.

## Estilo
- JavaScript moderno, sin dependencias innecesarias.
- Nombres descriptivos y funciones pequeñas.
- No guardes claves, tokens ni datos personales en el repositorio.
- Respeta la accesibilidad y las preferencias de movimiento reducido.
